## Notes
- Citation status per citation-verification.md — never leave this column blank or assume VERIFIED.
- DEL-7 tag per del7-evidence-hierarchy.md §1 — state the design (study-design-classification.md)
  first, then assign the tag from it.
- Directness and match ratings per evidence-directness.md (DIRECT/PARTIALLY DIRECT/INDIRECT;
  HIGH/MODERATE/LOW per dimension).
- Effect size must include a confidence interval where available — a bare point estimate or a
  significance label alone does not satisfy evidence-quality-appraisal.md.
