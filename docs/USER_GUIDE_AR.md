# دليل المستخدم — العربية

## ١. كيف تفكّرين في هذا المساعد

هو زميل يرفض التخمين. تسألينه سؤالاً سريرياً فيقول لك: ما الذي يمكن استنتاجه مما أعطيتِه، وما الذي
لا يمكن، وما الناقص، وأي قرار يغيّره كل نقص. ولا يملأ الفراغ بجواب معقول المظهر.

هذا هو التصميم كله، وما يلي نتيجة له.

## ٢. بدء الجلسة

```
/dana-dental-research:start
```

ثم صِفي سؤالك بلغتك، عربية أو إنجليزية. يختار المساعد المسار المناسب بنفسه، ويمكنك تسمية مهارة
بعينها إن أردتِ — القائمة في `INSTALLATION.md`.

## ٣. حالة سريرية

أعطي ما لديك. النقص طبيعي.

يتبع الجواب تسلسلاً ثابتاً: السؤال السريري ← سجل البيانات موسوماً ← النواقص مرتَّبة بحسب أثرها ←
حكم الكفاية ← قائمة المشكلات ← التشخيص التفريقي ← الخطورة ← الإنذار ← الثقة ← عوامل المريض ←
الأهداف ← الخطة المرحلية ← البدائل ← فحص عدم الرجعية ← الأدلة ← ما يجب التحقق منه ← **الخطوة
التالية الواحدة**.

| الوسم | المعنى |
|---|---|
| `[Reported]` | قاله المريض أو ورد في سجل — لم يُلاحَظ سريرياً بعد |
| `[Observed]` | لوحظ مباشرة أو موثَّق كفحص فعلي |
| `[Inferred]` | استنتاج معقول — ليس حقيقة مؤكدة، ويُذكر دائماً مع أساسه |
| `[Unknown]` | غير مذكور، ولا يجوز تخمينه |

**الاستنتاج لا يتحول إلى حقيقة** مهما بدا واضحاً. إن رأيتِ `[Inferred]` فالأساس مذكور بجانبه —
راجعي هل توافقين عليه.

## ٤. لماذا يرفض أحياناً

يحجب المساعد الخطة النهائية عندما:

- **البيانات غير كافية** للفعل المطلوب. دعم الوصف الدوائي يحتاج الحساسيات والأدوية والتاريخ الطبي
  وحالة الحمل؛ وأي `[Unknown]` بينها يحجبه.
- **فحص العلامات الحمراء غير مكتمل.** الأربعة عشر فحصاً يجب الإجابة عنها صراحة. وما لم يُجب عنه
  يُعدّ **غير مُقيَّم**، لا **غائباً**.
- **توجد علامة حمراء.** التصعيد أولاً، في أعلى الجواب.
- **الإنذار غير محدَّد** لسنٍّ تريدين ترميمه.
- **الحالة خارج النطاق** — خارج التركيبات الثابتة وطب الأسنان الترميمي التجميلي.

الحجب ليس عطلاً. لا يمكن تجاوزه بالإلحاح ولا بإعادة الصياغة. عالجي السبب المذكور، أو أحيلي.

## ٥. الإنذار

يُذكر بأربع فئات: **مُبشِّر**، **متحفَّظ**، **سيّئ**، **غير محدَّد** — على خمسة محاور منفصلة: السن،
اللثوي، الترميمي، التعويضي، والوظيفي/الإطباقي. ولكل محور أساسه وموجوداته المؤيدة والمعاكسة
ونواقصه ودرجة ثقته.

والإنذار العام هو **أسوأ** المحاور لا متوسطها — فالسن السليم لثوياً واليائس ترميمياً ليس
«متحفَّظاً إجمالاً».

**ولا تُنتَج أي نسبة مئوية.** فرقم البقاء المستخرَج من بيانات كرسي العيادة إحصاء مُختلَق.

## ٦. تخطيط العلاج

الخطط مرحلية: الطوارئ ← التثبيت وضبط المرض ← إعادة التقييم ← المرحلة الاختبارية القابلة للعكس ←
النهائية ← الصيانة.

وأربع قواعد **مُنفَّذة** لا مقترحة:

١. **ضبط المرض قبل التعويض النهائي.** لا ترميم نهائي فوق نخر نشط أو مرض لثوي نشط.
٢. **الإنذار قبل التعويض.** لا ترميم يُخطَّط لسنٍّ إنذاره غير محدَّد.
٣. **مرحلة اختبارية قابلة للعكس قبل العمل التجميلي غير القابل للعكس** — wax-up وmock-up، مع توثيق
   موافقة المريض.
٤. **البدائل تشمل دائماً عدم العلاج والمتابعة/التأجيل.**

وكل إجراء غير قابل للعكس يجب أن يذكر العمر المتوقع، ونمط الفشل، وعلامات الإنذار المبكر، وقابلية
إعادة العلاج، والتزام الصيانة، وكلفة الخطأ.

## ٧. كيف تُعالَج الأدلة

كل ادعاء ذي أثر يحمل فئة مصدره: إرشاد سارٍ، أو مراجعة منهجية، أو دراسة سريرية، أو إجماع، أو تعليمات
مصنّع، أو اجتهاد شخصي، أو غير محقَّق. وبيانات المختبر تُوسم ولا تدعم أبداً ادعاء تفوّق سريري.
والتسجيل النظامي يُوسم ولا يُعامَل دليلَ فعالية.

تُتحقَّق الاستشهادات عبر PubMed وCrossref معاً. والمقالات المتراجَع عنها تُستبعَد من التركيب لا
تُعلَّق. والتجربة والمنشور الذي يقرّرها تُحسبان دراسة واحدة.

**وإن تعذّر التحقق من مصدر، يُوسم «غير محقَّق» وتُعطَين سلسلة البحث لتنفيذها.** ولا يُختلَق مرجع
أبداً.

## ٨. الأسئلة التنظيمية السعودية

كل عبارة تنظيمية تحمل إحدى أربع حالات: محقَّقة، تتطلب تحققاً، غير منطبقة، أو غير معروفة/متعارضة.

واليوم، استعلام SFDA غير مُعتمَد، فيعود سؤال المنتج السعودي بـ**يتطلب تحققاً**. وتُذكَر حالة FDA
أو CE منفصلة وتُوسم بأنها غير قابلة للنقل. هذا هو الجواب الصحيح لا الفشل — تحقّقي مع الهيئة قبل
الشراء أو الاستخدام.

## ٩. الخصوصية

أزيلي المعرّفات قبل الكتابة. استخدمي مرجع حالة لا اسماً. وتذكّري أن الصور الشعاعية والمسوح تحمل
معرّفات مخفية، وأن قصّ الصورة لا يزيل بياناتها الوصفية.

وموافقة النشر منفصلة عن موافقة العلاج، ومنفصلة مرة أخرى لكل قناة. ولن ينتج المساعد محتوى تسويقياً
من مادة سريرية دون تأكيدك — في المحادثة نفسها — وجودَ موافقة نشر خطية محددة.

## ١٠. حين يبدو شيء خاطئاً

اطلبي منه إظهار تفكيره ومصادره. المساعد مصمَّم ليخالفك حين لا تدعم البيانات الاستنتاج، وألّا يخفّف
تحذيراً أمنياً لأنك اعترضتِ. وإن وافقك على كل شيء فهناك خلل — أبلغي عنه.

ولا تُدرجي أي معلومة تعرّف المريض في أي بلاغ.
