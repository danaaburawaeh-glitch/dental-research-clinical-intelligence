# البداية السريعة — العربية

## تعريف سريع

مساعد لدعم القرار السريري في طب الأسنان، يعمل داخل Claude Code. تعطينه الحالة، فيرتّب البيانات،
ويحدّد ما هو ناقص، ويفحص العلامات الحمراء، ويضع الإنذار، ويرتّب مراحل العلاج، ويسند ما يقوله
بأدبيات حقيقية مسترجَعة. وإن لم تكفِ البيانات، يتوقف بدل أن يخمّن.

## التنصيب (مرة واحدة)

```bash
claude plugin marketplace add danaaburawaeh-glitch/dental-research-clinical-intelligence
claude plugin install dana-dental-research@dana-dental
```

للتحقق: `claude plugin list` (يُتوقَّع v1.0.1 مُفعَّلاً) و`claude plugin details dana-dental-research`
(يُتوقَّع ٩ مهارات).

## ابدأ خلال 5 دقائق

1. افتحي Terminal واكتبي `claude` ثم Enter.
2. اكتبي `/dana-dental-research:start` ثم Enter.
3. صِفي الحالة بلغتك، أو الصقي القالب أدناه.

لا حاجة لحفظ أوامر — المساعد يوجّه سؤالك بنفسه. تستطيعين الكتابة بالعربية، وتبقى المصطلحات
السريرية بالإنجليزية حين تكون الدقة أهم.

## مراجعة خطة

> «راجعي هذه الخطة: فينيرز للفك العلوي كامل، عشر وحدات، المريضة لديها نزف لثوي معمّم وتذكر
> صريراً ليلياً.»

المراجعة **عدائية عمداً**: تبحث عن الافتراضات غير المعلنة، وأخطاء التسلسل، والبدائل المحافظة
المُغفَلة، وفجوات الإنذار. لا تعيد سرد خطتك بالموافقة.

## البحث العلمي

> «ما الدليل على الزرع الفوري مقابل المؤجل في المنطقة الجمالية؟»

تحصلين على: السؤال مصاغاً بصيغة PICO، والبحث المنفَّذ فعلياً، وكل دراسة بتصميمها وحدودها،
وخلاصة بمستوى دليل معلن، ومدى انطباقها على مريضتك، ثم — منفصلاً — ما لا يجيب عنه الدليل.

## مقارنة الخيارات

> «قارني الليثيوم ديسيليكات والزركونيا المونوليثية لتاج خلفي عند مريض صرير.»

كل مقارنة تتضمن **عدم العلاج** و**المتابعة/التأجيل** كخيارين حقيقيين، مع الكلفة البيولوجية والعمر
المتوقع ونمط الفشل وعبء الصيانة لكل خيار.

## سؤال تنظيمي سعودي

> «هل هذا اللاصق مسجَّل للاستخدام في السعودية؟»

الجواب الصادق اليوم هو **يتطلب تحققاً (REQUIRES VERIFICATION)** — فاستعلام SFDA يحتاج بيانات
اعتماد غير مهيّأة في هذا الإصدار. وموافقة FDA أو علامة CE تُذكَر منفصلة وتُوسم بأنها **غير قابلة
للنقل** إلى الوضع النظامي السعودي. تحقّقي مع الهيئة قبل الشراء أو الاستخدام السريري.

## قاعدتان مهمتان

**أزيلي المعرّفات أولاً.** لا تُدخلي الأسماء ولا أرقام الهوية أو الإقامة ولا أرقام الملفات.
اكتبي «مريضة عمرها ٤٥ سنة» بدل الاسم. وتذكري أن الصور الشعاعية والمسوح تحمل غالباً معرّفات مخفية
في بياناتها الوصفية، وقصّ الصورة لا يزيلها.

**فشل البحث ليس نتيجة.** إذا تعذّر الاسترجاع فهذا يعني أنه **لم يُجرَ بحث**، لا أنه «لا يوجد
دليل».
